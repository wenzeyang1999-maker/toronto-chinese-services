## ✅ 已完成（已上线 / 已部署）

### 1. 核心交易闭环（说明书 §6 · 审计「墙1」）
- **订单状态机**：`orders` 表 + 双向确认（create / confirm / cancel / **complete**）。会话「标记成交」→ 双方确认 → 完工。
- **成交金额录入**：标记成交时可填金额 → GMV/客单价有数据地基（金额选填）。
- **完工拍照存证**：师傅「标记完工」强制传 1–3 张现场照，双方可见。
- **我的交易**：报价请求 / 我接的单 / 成交订单 三合一带 tab；名片墙「已成交 N 单」。

### 2. 信用与评分体系 V2（一期 + 二期全部上线）
- **双向盲评**：客户评师傅 / 师傅评客户，防报复（双方都评或 48h 自动 5★ 才公开）、近 30 单加权。
- **综合信用分引擎** `user_trust`：认证 + 完工 + 口碑 − 有效投诉 → 档位 + 门槛。
- **三处门槛拦截**：受限师傅（≥5 有效投诉 / 严重仲裁判负）不能发单 / 抢单 / 被自动派单。
- **档位徽章**（需求详情客户档位、师傅主页）+ 管理员后台调分 + 纠纷「标记严重」。

### 3. AI 纠纷仲裁（文字版 MVP）
- 任一方对 confirmed/completed 订单「发起纠纷」→ 后台工单 + 通知 admin。
- `arbitrate-dispute` 边缘函数（Groq）出「AI 初步参考意见（非约束）」+ 人工终判。纯文字，照片供人工看。

### 4. 会员体系基础设施（**已在跑**，收费部分关闭）
- **新用户 3 个月 L2**（邮箱/手机/Google 通用，到期回落）。
- **推荐加时**：每满 3 个成功推荐 → L2 +10 天。
- **启动期全员保底 L2**：`effective_member_level` 除 L3 外一律按 L2（收费上线时改回 L1）。
- **发帖额度**：同类「同时在架」上限 **L1=1 / L2=3 / L3=10**，删/关自动释放、编辑不受限、管理员豁免。
- ⚠️ 收费/邻豆/付费排序由 `MONETIZATION_ENABLED=false` 全关，界面无付费墙。

### 5. 名片墙六维（说明书 §4.3 齐全）
星级 · 接单量 · 距离就近排序 · 持牌绿芯片 · 商业保险盾牌 · 经营主体(自雇/公司) · 社媒外链。
认证徽章由**后台核验**决定有无（防自我认证 + 防花钱解锁）。

### 6. 城市框架（当前仅多伦多）
定位自动切城 · 未开通城市轻量拦截弹窗 · 三级地区联动选择（可跨城帮亲友发单）。开新城只需置 `opened=true`。

### 7. 列表性能范式（五大类已铺满）
分页 + 无限滚动（IntersectionObserver）· 计数去规范化（`_count` 字段 + 触发器，不前端二次查）· 骨架屏 + 真错误态。

### 8. 地图精简（回归说明书「地图后台化」）
列表默认、地图可选（记忆用户选择）· 切「服务商」模式默认进「🚨 急单地图·找客户」· 急单/普通需求分色 + 只看急单筛选。

### 9. 语音输入（Groq Whisper）
发需求 + AI 客服同一套 · 普通话/英语/中英混说 · 大按钮 · 修复 Safari/iOS 无结果 + 抑制静音幻觉。

### 10. 信息架构 / 命名统一
个人中心重排 · 「我的主页」→「我的名片」· 「发布服务」→「服务卡片」· 「AI 帮你找」→「AI 智能匹配」·
交易三合一 · 通知设置并入「帐号和安全」· 收藏+关注合并 · 底部「放大镜」→「AI 客服」。

### 11. 认证 · 安全 · 隐私（审计整改）
持牌/保险徽章（防自我认证）· 录用后才解锁精确地址（列级 + 表级 REVOKE，仅中选师傅经 RPC 取）·
email 收口（非 admin 不可抓全表邮箱）· users 表 PII 收口 · 存储 RLS 路径劫持修复 · 资质图隐私提示。

### 12. 认证登录
手机验证码注册 + 登录（Supabase 原生 + Telnyx）· Google 登录修复 · 手机注册自动已验证（同步 `phone_verified`）·
邮箱绑定/验证流程（身份验证页「去绑定/去验证」，不阻塞登录）· 会话长期保持 · 注册后可直接进首页。

### 13. 🆕 成本 / 用量护栏（2026-07-24 这一轮 · 免费额度防爆）
- **图片 egress**：上传压缩 2.5MB→400KB；`/api/img` Vercel 边缘代理 + 按需缩图（WebP），重复浏览走 Vercel CDN 不计 Supabase egress。
- **邮件**：派单通知只在**紧急单**发、最多前 5 家；社交类（消息/关注/评价/粉丝广播）改站内红点 + web push；渠道 Resend→**Brevo**。
- **Groq**：AI 搜索 / 询价解析 429 自动回退 8B；内容审核本就 8B + fail-open。
- **短信(Telnyx)**：每日预算护栏（超 300/天停发）+ 达 200 给管理员站内预警。
- **Google Maps**：已排查——无 Places 自动补全（地址用免费 Nominatim、仅点击请求），无需改。
