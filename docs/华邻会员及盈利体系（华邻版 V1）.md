## 0. 三条硬原则（写死，不可因收费而妥协）

### 原则 1 —— 付费只解除「免费额度」，永远不解除「信用受限」🔴 最高优先级
- 信用体系现有门槛：`≥5 有效投诉 / 严重仲裁判负 → 停止抢单`（见 [信用体系 V2](华邻信用及评分体系（华邻版%20V2）.md) §D）。
- **受限师傅无论买不买会员、充不充邻豆，一律不能抢单 / 不能查看客户精准联系方式。**
- 付费能买的**只有**：把「每月 3 次免费额度」变成「无限次」。它**买的是数量，不是资格**。
- 判定顺序（代码里必须是这个顺序，不可颠倒）：
  1. **先查信用门槛** `can_participate()` → 受限直接拦截，付费状态完全不参与判断；
  2. 通过后**再查额度** → 免费用户看剩余免费次数，付费用户放行。
- 一句话：**信用是闸门，会员是流量。闸门关着，交多少钱都过不去。**

### 原则 2 —— 认证徽章永远免费显示，绝不靠钱解锁
- **后台核验过的认证（持牌 / 商业保险 / 实名 / 商户认证）= 永久免费显示**，与会员等级无关。这是**安全信息**，藏起来会误导客户、砸信用体系。
- 会员付费能买的是**展示增强**，不是信任本身：
  - ✅ 可付费：社媒外链跳转（小红书/IG/FB）、名片美化、多张名片、名片墙置顶、有效期延长。
  - ❌ 不可付费解锁：认证徽章的**有无**。徽章有无只由「后台是否核验通过」决定。
- 反面例子（禁止）：「买了 L2 才显示已认证」——这会让「付费」被误读成「已认证」。

### 原则 3 —— 匹配排序主键是信用 + 口碑，付费只做同档内加权
- 名片墙 / AI 匹配 / 急单推送的**排序主键 = 信用分 + 口碑星级**。
- 付费**只在同一信用档位内**起作用（并列时优先、同档内轻微加权），**不做跨档覆盖**。
- 即：一个 🔵良好档 的 L3 付费商家，**排不到** 🟢优质档 免费商家的前面。花钱能在「自己这一档」里冒头，不能压过更靠谱的人。
- 目的：保护客户体验。让「花钱」帮你被更多人看到，而不是让「花钱」凌驾于口碑之上。

## 一、整体逻辑：C 端永久免费，B 端按效果付费

| | 谁 | 策略 | 原因 |
|---|---|---|---|
| **发单方** | C 端客户（找服务） | **永久免费、零门槛** | 纯消费方，收费即杀死网络效应 |
| **接单方** | B 端师傅 / 商家 | **免费体验 + 按量/按权益付费** | 靠平台赚钱的一方才付费，符合海外华人「重性价比」心理 |

会员体系（L1/L2/L3）与邻豆**只面向 B 端**（师傅 / 商家 / 高频发商业信息者）。C 端客户永远不进这套收费。

## 二、会员三档

> 价格为规划值，**启动阶段不生效**（`MONETIZATION_ENABLED=false` 时全员等价 L2 无限额度）。

### L1 · 普通会员（免费 / $0）
- **定位**：零门槛吸粉、跑通闭环、培养习惯。
- **谁会用**：普通 C 端客户（找服务）、新进师傅 / 小商家（试水）。
- **免费能力**：免费发需求、免费 AI 智能解析、免费搜索、免费浏览双列名片墙。
- **额度与限制**（为升级铺垫，**受信用门槛前置**）：
  - 发帖：每 7 天免费发布 1–2 条服务/二手/租房，信息有效期 7 天。
  - **抢单额度：每月 3 次免费**「查看客户精准联系方式 / 正式抢单」。超出后按次付费（邻豆）或升级。
  - 展示：名片不带付费增强，双列墙按信用+口碑排序（不因免费而人为压后，只是没有付费加权），不可绑社媒外链。
- **注意**：免费额度**只在信用未受限时**才有意义。受限用户 0 次，且不可购买解锁（原则 1）。

### L2 · 黄金会员（专业师傅 / 进阶商户，$19.99/月，或 $199/年）
- **定位**：兼职师傅、个体户、小型服务商（独立接送、保洁、Handyman）。
- **不订月费也可**：按 $2.99/次 购买单次抢单/发布额度（轻度用户）。
- **核心权益**：
  - **无限次抢单**（解除免费额度限制——**但仍受信用门槛约束，受限即停**）。
  - 社媒外链解锁：主页可绑定并跳转小红书 / IG / FB。
  - **名片美化 + 认证徽章展示增强**（注意：徽章有无仍由后台核验决定，付费只是让已认证的展示更醒目——原则 2）。
  - 发帖增量：可维护 3 张不同类目名片，有效期延长至 30 天。
- **约束**：地图与搜索曝光「常规优先」（同档加权，不跨档）；享基础 AI 客服与完工存证支持。

### L3 · 至尊会员（皇冠商户 / 商家 VIP，$49.99/月，或 $499/年）
- **定位**：大型公司（专业搬家、大装修、冷暖气）、高频商业广告主。
- **核心权益**：
  - **顶格曝光**：在其黄金二级类目内，名片享同档优先轮播 + 高亮边框（**同档内**，不跨信用档——原则 3）。
  - 急单地图优先强推：附近有紧急需求时，L3 **同档**内优先收到强提醒弹窗。
  - 品牌特权：最多 10 张名片、名片永久不失效。
  - AI 匹配加权：客户 AI 语音搜索/找师傅时，**同档**内 L3 优质商家优先匹配。
  - 专属客服与纠纷快速仲裁。
- **约束**：必须保持 4.5 星以上 且 无重大投诉记录，否则平台暂停 L3 曝光特权（**付费不豁免信用要求——原则 1 的延伸**）。

## 三、单次点播 · 邻豆（Pay-As-You-Go）

海外华人厌恶订阅、偏好「用多少买多少」。邻豆是**平台内预付点数**，非月费用户也能即买即用。

### 3.1 计费动作（精确框定，只对「变现动作」收费）
**只有以下动作消耗额度/邻豆**，其余一律免费：
- ✅ **正式抢单 / 查看客户精准联系方式**（核心变现动作）。
- ✅ **商业帖置顶 / 加权曝光**（可选增值）。

**永远免费、不计费、不限量**：
- 浏览名片墙、搜索、发需求、AI 智能解析、**主动联系+不发帖只看在线商家**（与信用体系口径一致）。

### 3.2 价目（规划，不上线）
- 单次抢单：**$2.99 / 次**；商业帖置顶：**$4.99 / 3 天**。
- 加油包（充值优惠，「囤优惠」心理）：
  - 充 $10 赠 $2（约 4 次抢单额度）；
  - 充 $50 赠 $15（单次抢单低至约 $1.9/次）。

### 3.3 「无果退费」信任破局点（核心）
- 若师傅支付了抢单点数/费用，但客户**最终未选择任何师傅或取消订单**，平台**全额退还该次点数**。
- 消除华人师傅「平台扣钱却吃空饷」的疑虑。
- **实现要点**：点数在抢单时**冻结（hold）**而非立即扣除；订单成交才实扣，客户放弃/无果则解冻退回。

### 3.4 合规说明（重要）
- 邻豆 = **平台内预付服务额度（SaaS 充值）**，用于购买「抢单次数/曝光」等平台功能。
- **不是代收订单钱款**，师傅与客户之间的服务费仍双方私下结算，**平台不经手订单支付**——因此邻豆**不违反「平台不经手支付」原则**，无果退费也只是退平台点数。

## 五、与信用体系的接口（代码必须遵守的判定链）

抢单 / 查看联系方式的完整判定，**顺序不可变**：

```
1. can_participate(user)  ── 信用门槛（受限？→ 直接拒绝，付费状态不参与）
      │ 受限 → ❌ 拦截："信用受限，暂停抢单，请先处理投诉/申诉"
      ▼ 通过
2. MONETIZATION_ENABLED?  ── 总开关
      │ false（当前）→ ✅ 放行（无限额度，不计费）
      ▼ true（未来）
3. membership / 邻豆额度 ── 免费用户查剩余 3 次；付费/有币 → 放行；额度用尽 → 引导购买
```

- **关键**：第 1 步永远在第 3 步之前。信用受限在任何付费状态下都拦截。
- 认证徽章渲染：**只看后台核验字段**（`business_verified` / 持牌 / 保险 / 实名），**不看会员等级**（原则 2）。
- 排序函数：主键 `信用分 + 口碑`，会员等级仅作**同档 tie-break 加权项**（原则 3）。

## 六、启动阶段策略 & 上线分期

### 现在（启动阶段）
- `MONETIZATION_ENABLED = false`：**全员无限额度、无付费墙**，等价 L2 体验。
- 目的：冷启动期供给端（师傅）不能被收费吓走，先把急单/成交量做起来。
- **但骨架先建好**：会员等级字段、额度判定链、认证/排序的原则隔离——都先落代码，只是被开关关着。
- 老板去研究线上收款（Stripe / 微信支付 / e-Transfer 等）。

### 上线分期（收款方案确定后，逐步翻开关）
- **一期**：开启「免费 3 次 + 单次邻豆付费」（最轻，先验证付费意愿）。
- **二期**：开启 L2/L3 月费订阅 + 权益（社媒外链、多名片、同档曝光）。
- **三期**：加油包充值优惠 + 无果退费冻结/解冻逻辑。
