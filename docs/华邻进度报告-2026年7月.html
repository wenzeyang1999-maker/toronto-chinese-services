这个月是从「功能铺满」转向「能真正跑起来、扛得住成本、建立信任」的一个月。三条主线： ① 把交易—信用—纠纷的闭环打通并上线， ② 会员/盈利骨架就位(收费开关先关着)， ③ 一整轮成本用量护栏，保证免费额度内不爆。以下按主题归纳。

一、核心交易闭环 上线

✓订单状态机 + 双向确认已上线
`orders` 表，会话「标记成交」→ 双方确认 → 完工全流程；标记成交可填成交金额，为 GMV/客单价打下数据地基。
✓完工拍照存证已上线
师傅「标记完工」强制上传 1–3 张现场照，双方可见，建立交付信任。
✓「我的交易」三合一已上线
报价请求 / 我接的单 / 成交订单 合并带 tab；名片墙展示「已成交 N 单」。

二、信用与评分体系 V2 一期+二期全上线

✓双向盲评 + 防报复已上线
客户评师傅 / 师傅评客户，双方都评或 48h 后自动 5★ 才公开；近 30 单加权。
✓综合信用分引擎 `user_trust`已上线
认证 + 完工 + 口碑 − 有效投诉 → 档位 + 门槛。受限师傅(≥5 有效投诉/严重判负)不能发单/抢单/被派单，三处拦截。
✓档位徽章 + 管理员调分已上线
客户档位、师傅主页徽章；后台可人工调分、纠纷「标记严重」。

三、AI 纠纷仲裁(文字版 MVP) 上线

✓发起纠纷 → 后台工单 + AI 初步参考已上线
任一方对 confirmed/completed 订单发起纠纷 → 通知 admin；`arbitrate-dispute` 边缘函数(Groq)出「AI 参考意见(非约束)」+ 人工终判。

四、会员体系基础设施 已在跑 · 收费关闭

✓新用户 3 个月黄金(L2)试用已上线
邮箱/手机/Google 通用，到期回落；启动期全员保底 L2(收费上线时改回 L1)。
✓推荐加时：每 3 个成功推荐 → L2 +10 天已上线
可累计叠加(本月由「每 10 人 +30 天」调整为「每 3 人 +10 天」，门槛更低更易触发)。
✓发帖额度：L1=1 / L2=3 / L3=10已上线
同类「同时在架」上限，删/关自动释放、编辑不受限、管理员豁免。
✓盈利骨架就位(邻豆/付费排序/付费权益)开关关闭
`MONETIZATION_ENABLED=false` 全关，界面无付费墙；三条硬原则写死：付费不解信用门槛、认证徽章不靠钱、付费不跨档覆盖口碑。
